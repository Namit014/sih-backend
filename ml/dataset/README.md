# ML Dataset Directory

This directory contains the training data for the X account risk model.

**Important Note:**
The `accounts.csv` file currently present here is **SYNTHETIC DATA** generated for development and pipeline validation.
It does NOT contain real X account data and models trained on it will not be accurate for production classification.

Before finalizing a production model, this synthetic dataset must be replaced with a real-world labeled dataset containing manually verified normal and suspicious accounts.
